# Files
1. `books.json` - Contains two book records in a top-level `books` array.
2. `books.html` - Retrieves and displays JSON data using the `fetch()` API.
3. `jquery-dom.html` - Demonstrates jQuery DOM operations and event handling.

# How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Install the Live Server extension (if not already installed).
4. Open `books.html` using Live Server (do not open directly via `file://`).
5. Open `jquery-dom.html` using Live Server (or in a browser).
